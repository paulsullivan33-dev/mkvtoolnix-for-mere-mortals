# The subtitle track is the long pole. In the source file,
# cue 2 runs 00:04.5 --> 00:07.5 and cue 3 runs 00:08.5 -->
# 00:11.5. A cue that starts before a split point is written
# whole into the earlier part, so part 1 honestly lasts
# 7.5 s and part 2 starts at its own zero but runs to the
# end of cue 3 -- 6.5 s of declared length. When the parts
# are appended, mkvmerge offsets each file by the declared
# duration of the ones before it: 7.5 + 6.5 + 2.03 = 16.03 s.
# The picture and sound are all present; the joins carry
# the extra time. Split parts are for sending and storing,
# not puzzle pieces that rebuild the original exactly.
