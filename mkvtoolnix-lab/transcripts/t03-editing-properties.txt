# Every track claims to be "default" -- each source file had
# only one track, and mkvmerge kept each file's own default
# flag. A player may start this film with the commentary
# playing and the subtitles on. Fix it in place:

$ mkvpropedit work/fixed.mkv \
    --edit info --set "title=The Lighthouse at Gull Rock (evening cut)" \
    --edit track:v1 --set language=eng \
    --edit track:a2 --set flag-default=0 \
    --edit track:a2 --set "name=Commentary (220 Hz tone, alternate take)" \
    --edit track:s1 --set flag-default=0
The file is being analyzed.
The changes are written to the file.
Done.
exit: 0
